Missing Episode Marker

Sonarr connection

As the Jellyfin server reaches it, e.g. http://sonarr:8989 when both run on the same Docker network.
Sonarr → Settings → General → API Key.

When to check

A full check asks Sonarr about every series. With "React to library changes" on, most changes are handled straight away, so the timer is mainly a safety net, e.g. for episodes that pass the grace period or files deleted outside Jellyfin. Once a day is plenty for most servers. This setting controls the task "Mark series with missing episodes" under Dashboard → Scheduled Tasks.
When Jellyfin refreshes a series it may switch back to the poster file in the series folder. With this on, the marker is put back within a few seconds. A series is also rechecked about 1.5 minutes after episodes are added or removed, so a completed show loses its marker without waiting for the next full check.

Grace period

For shows that are still airing: an episode only counts as missing once it aired this long ago.
Example with 4 weeks: an episode that aired on 1 March only marks the show from 29 March if it is still missing. This applies to every season, so a gap in season 3 of a show that is airing season 5 is marked as soon as those season 3 episodes are older than 4 weeks (which they usually are). Unaired and TBA episodes never count.

What to mark

Turn off and run a check to restore every original poster.

Special episodes (season 0)

Specials are often skipped on purpose, so by default they never mark a show. "Only for series with a rule" lets you pick a handful of shows below whose specials matter. This setting applies to anime too.
"Monitored in Sonarr": manage it in Sonarr by monitoring only the specials you want.
"Chosen in the rules": click "Choose…" on a rule to tick specials from a list. A rule with nothing chosen counts all of that series' specials.
Sonarr numbers specials by TVDB's season 0, which often differs from IMDb (IMDb's "S2E4" might be special 8 in Sonarr). The picker shows titles and dates, so you don't need the numbers.

Anime

Example: an anime with 100 episodes where episodes 40-45 are filler. If only 42 is missing and this is off, the anime is not marked. Turn it on if you want every episode, filler included. You can change this per anime below.
Specials for anime follow the settings on the TV shows tab.

Filler lists

Rules for anime

Filler list page: the end of the series' address on the filler website, e.g. "one-piece" for animefillerlist.com/shows/one-piece. Leave empty to find it automatically from the title; fill it in if the automatic match fails (the report shows where filler data came from).
Manual filler: filler episodes by absolute number, e.g. "26, 97-106". When filled in, it is used instead of the website.
