Sonarr decides what is checked: shows and episodes that are unmonitored in Sonarr are ignored (that includes specials). To stop a show from being marked, unmonitor it, or the episodes you don't want, in Sonarr.

Keeping markers up to date

A check is only three quick requests to Sonarr, so every 1–5 minutes is fine. 0 = no timer (only the webhook and library changes start checks).

Sonarr webhook (recommended)

With the webhook, Sonarr tells the plugin the moment it grabs, imports or deletes an episode, so a marker turns purple, disappears or comes back within seconds instead of at the next timer check. The timer still catches things Sonarr doesn't send events for, such as a download that stalls or an episode passing the grace period.

How to add it in Sonarr
  1. In Sonarr open Settings → Connect and click +, then choose Webhook.
  2. Name: Jellyfin markers (anything you like).
  3. Notification triggers: tick On Grab, On File Import, On File Upgrade, On Import Complete (if listed), On Series Delete, On Episode File Delete and On Manual Interaction Required (if listed). Untick the rest.
  4. Webhook URL: paste the URL above. Method: POST. Leave username and password empty.
  5. Click Test (a green tick means Sonarr reached Jellyfin), then Save.
"New secret" makes the old URL stop working; update it in Sonarr afterwards. The URL contains a secret, so don't share it.
Puts a marker back within seconds when Jellyfin swaps a marked poster (e.g. after a metadata refresh), marks a new show as soon as its poster has downloaded, and checks again 30 seconds after episodes are added or removed.

Poster repair

Sometimes Jellyfin ends up with no poster, or uses a frame from the video instead of a real poster (you can tell because it is wide instead of tall). With these on, the plugin asks Jellyfin to fetch the poster again (every few hours, and when you click "Check now"). Only the poster is refreshed, nothing else. Each item is retried at most once a week. Movies are only repaired, never marked.

Seasons without a poster are included: apps show the show cover in their place, which would carry the show's marker. If no season poster can be found, the season gets an unmarked copy of the show poster (this part works even with repair turned off, and is undone by "Remove all markers").

How markers work

Each episode gets one state. A season shows its most important state, the show cover the most important state of all its seasons: missing > stalled > downloading > on the way. Seasons with nothing going on get no marker.
Missing: aired longer ago than the grace period, no file, not downloading.
Download stalled: in Sonarr's queue with a warning or error (stalled, failed, waiting for manual import, …).
Downloading: in the queue and already past the grace period (so it would be "missing" otherwise).
New episode on the way: in the queue while still within the grace period, or not even aired yet.
An episode within the grace period that is not downloading gets no marker at all.
Turn off and save to restore every original poster.

Grace period

Example with 4 weeks: an episode that aired on 1 March and still has no file turns the show red on 29 March. Before that it only gets a marker while it is downloading (blue).

Anime

Example: an anime with 100 episodes where episodes 40-45 are filler. If only 42 is missing and this is off, the anime is not marked. Turn it on if you want every episode, filler included. You can change this per anime below. (Unmonitoring the filler episodes in Sonarr has the same effect.)

Filler lists

Adjustments per anime

Missing filler: overrides the setting above for this anime.
Filler list page: the end of the anime's address on the filler website, e.g. "one-piece" for animefillerlist.com/shows/one-piece. Leave empty to find it automatically from the title; fill it in if the automatic match fails (the report shows where filler data came from).
Manual filler: filler episodes by absolute number, e.g. "26, 97-106". When filled in, it is used instead of the website.
